# 软考高级系统架构设计师 · 邪修知识卡片

每张卡片六段：官方硬核定义 / 邪修大白话 / 案例降维打击 / 论文预制菜 / 考官避坑 / **选择题秒杀**。

**全局入口**

- [背诵总提纲.md](背诵总提纲.md)：全部模块的一页纸骨架 + 口诀 + 生活类比 + 案例/论文模板，先背它再看卡片。
- [交互学习面板/index.html](交互学习面板/index.html)：双击用浏览器打开，按 7 天冲刺设计：
  - 冲刺台：逐日作战表（上午 / 下午 / 晚上），每项任务一键跳到对应练习；到期卡、错题、薄弱模块一屏看完。
  - 考点雷达：26 小时按 S/A/B/C 分级，附原书分值题型、邪修策略、343 条必会点打勾清单。
  - 口诀背卡：225 张卡，7 天压缩版间隔重复（不会当天再来，模糊明天，会了 2/3/5 天后）。
  - 反射训练：触发词闪电战（3 秒倒计时）、62 组顺序默写、质量属性判官、四点判官、口诀解码。
  - 刷题模考：口诀题 + 书本练习 + 两套模拟卷共 259 题，按模块 / 来源 / 小时筛选，75 题 150 分钟限时模考出成绩单。
  - 案例：对比题背默、模拟卷 10 道案例真题演练、选答题主题包、答题模板。
  - 论文工坊：项目档案 → 12 个常见题目的契合度与改写提示 → 自动生成摘要和段落骨架 → 120 分钟计时打字。
  - 兵法·心法：考场策略、记忆方法说明、项目记忆宫殿。
  - 另有总提纲、场景实验室、速查。改完提纲后运行 `node scripts/prepare-site.js` 再刷新。
  - 题库 `bank.js` 由 `node scripts/build-bank.js` 从书的 Markdown 抽取；书本身不进仓库，所以生成结果要一起提交。

上午题先翻 [00-选择题秒杀总表.md](00-选择题秒杀总表.md)（计算、耦合、缓冲、知产等跨章套路），对上考点再打开对应卡片第 6 段。
