# 软考高级系统架构设计师 · 邪修知识卡片

每张卡片六段：官方硬核定义 / 邪修大白话 / 案例降维打击 / 论文预制菜 / 考官避坑 / **选择题秒杀**。

**全局入口**

- [背诵总提纲.md](背诵总提纲.md)：全部模块的一页纸骨架 + 口诀 + 生活类比 + 案例/论文模板，先背它再看卡片。
- [论文终版模板.md](论文终版模板.md)：论文最终模板。含对原稿的评估、项目事实表（所有数字只取这张表）、摘要加四段母版（带 A S B B2 C E D 七个槽位）、字数与时间预算、15 天背诵排期。
- [论文套题库.md](论文套题库.md)：近 10 次真题的题材矩阵、四象限、押题顺位、兜底三步法，以及 K01 至 K15 十五套槽位内容。抽到什么题，就把母版里的槽位换成对应这一套。改完两个文件后运行 `node scripts/prepare-site.js`，面板会重新解析；手机背诵版 PDF 用 `node scripts/build-essay-pdf.js 论文终版模板.md 论文终版模板.pdf` 重新生成（套题库同理）。
- `论文模板最新版本.md`、`论文微服务背诵稿.md`、`论文通用满分模板.md` 是更早的版本，已被终版取代，保留作对照。
- [交互学习面板/index.html](交互学习面板/index.html)：双击用浏览器打开，按 7 天冲刺设计：
  - 冲刺台：逐日作战表（上午 / 下午 / 晚上），每项任务一键跳到对应练习；到期卡、错题、薄弱模块一屏看完。
  - 考点雷达：26 小时按 S/A/B/C 分级，附原书分值题型、邪修策略、343 条必会点打勾清单。
  - 口诀背卡：225 张卡，7 天压缩版间隔重复（不会当天再来，模糊明天，会了 2/3/5 天后）。
  - 反射训练：触发词闪电战（3 秒倒计时）、62 组顺序默写、质量属性判官、四点判官、口诀解码。
  - 刷题模考：口诀题 + 书本练习 + 两套模拟卷共 257 题（题库里答案与解析矛盾的 5 题已按解析订正、OCR 残片已清理、缺图/选项重复的 2 题已排除，见 `scripts/patch-bank.js`），按模块 / 来源 / 小时筛选，75 题 150 分钟限时模考出成绩单。
  - 案例：对比题背默、模拟卷 10 道案例真题演练、选答题主题包、答题模板。
  - 知识图谱：约 130 个概念、250 多条关系，按类型 / 模块 / 掌握度 / 项目用到配色；点节点看解释、背卡、相关论文套题；“关联挑战”练“看到一个概念，能想到它和谁挂钩”，把零散知识连成网。
  - 动画剧场：8 个可操作的动画，每个都挂着对应的考点卡和论文套题。项目沙盘（开学周故障复盘，同步等待 / 本地消息表 / 熔断三种架构对比）、熔断器状态机、秒杀漏斗、分布式事务四种方案、负载均衡与一致性哈希环、CAP 分区、Lambda 与 Kappa、六边形架构。可直达：`index.html#anim:simId=sandbox`。
  - 刷题模考（秒杀版）：答完一题不只看对错，给一张秒杀卡——题眼 → 一句结论；四个选项各自考什么；“如果答案换成它，题干会怎么出”；串联的概念链和相关背卡。可按题号跳到任意一题，题号颜色表示对/错/蒙对；A–D 键作答，←/→ 换题；选对但没把握可记入错题本。笔记在 `quiz-notes.js`，限时模考保持原样，交卷后的错题解析里也附秒杀卡。
  - 论文工坊：终版模板（母版 + 7 个槽位）+ 15 套题材套题（热点与潜在押题）。题材雷达（考场选题器、近 10 次真题落点、四象限防踏空、15 天排期）、终版模板（可遮住默写）、套题背诵（槽位级间隔重复）、默写训练（逐句接龙：先看上一句和首字，越熟提示越少；忘了的当场回炉，到期自动回来；数字和术语单独判分，逐字标出漏写；母版句子十五套共用；句签可跳到任意一句默写或“先看答案记一记”；右侧“辅助记忆”开关给出骨架词、句型、首字串和数字对应的事实，术语库在 `essay-vocab.js`，漏词直接往里补；Alt+←/→ 换句）、组装与默写核对（逐句标漏，可只默母版骨架）、事实表、120 分钟限时写作。
  - 兵法·心法：考场策略、记忆方法说明、项目记忆宫殿。
  - 另有总提纲、场景实验室、速查。改完提纲后运行 `node scripts/prepare-site.js` 再刷新。
  - 题库 `bank.js` 由 `node scripts/build-bank.js` 从书的 Markdown 抽取；书本身不进仓库，所以生成结果要一起提交。
